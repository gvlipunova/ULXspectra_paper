\subsection{Parameters}
\label{sec:model:params}

Table~\ref{tab:params} lists the parameters of the model.
The fits use the presets of \code{ULX.conf} in Table~\ref{tab:fitpresets}, which relates each of them to the flow rules of Table~\ref{tab:presets} and to the rules for the  spherization radius $\Rsph$, see Sect.~\ref{sec:radii:sph}.
Parameters that a preset does not free keep the defaults of Table~\ref{tab:params} or the values the preset sets; for a free parameter the default is only the centre of the starting positions of the chains and does not enter the prior; for a NS, $M = 1.4\,M_\odot$, and $\log(\rmag/\rg)$ has a flat prior over (0.65, 4.65).
% source: ULX.conf.example (ULXspectra-mc commit 7ba8568; the working ULX.conf, git-ignored, has the same presets;
%         only [DEFAULT] KEV_max differs, 100 vs 1, overridden by --Emax in the fits); log_m_bh = 0.14612803;
%         README "Model Presets" (NS table and the note below it); PLAN C23
Except for BH0, BH2 and NS2, all presets use the $\Mdot(r)$ profile of the main model (Eq.~\ref{eq:mdot_setin}).

No NS preset leaves the wind toll $\epsilon_{\rm w}$ free: all NS fits use the default 0.5, except NS3a, which has no wind and $\epsilon_{\rm w} = 0$.
% source: calculation session 2026-11-23 (Note 8 and its reply; ULX.conf: no NS preset, current or old NS1-NS7r, has eps_w free);
%         NS3a eps_w = 0: ULXspectra-mc ccf2bb8 (PLAN 8.3), for the mc28_0p3-10keV round; the earlier NS3a fits (mc_0p3-10keV) had 0.5.
% AUTHOR: until the mc28 NS refits replace the mc_0p3-10keV ones in the paper, NS3a fits shown have eps_w = 0.5; adjust the clause then.
Except in the P07 scenario (BH0), where it sets $\mdot_{\rm in}$ and $\Rsph$ (Eqs.~\ref{eq:mdot_in_P07} and~\ref{eq:rsph_P07}), $\epsilon_{\rm w}$ changes neither the mass loss nor the geometry of the wind.
It only sets how much of the energy released inside $\Rsph$ the disc radiates, through $T_{\rm disc}$ (Eq.~\ref{eq:Tdisc}), and with it the energy budget of the wind (Sect.~\ref{sec:wtemp:budget}).
All NS presets except NS2 use the main profile, in which $f_{\rm in}$ sets the mass loss, so for them a free $\epsilon_{\rm w}$ would be one more parameter of the brightness.
The BH3a fits, in which $\epsilon_{\rm w}$ is free, show what happens then.
Six of the 14 sources reach the lower edge, $\epsilon_{\rm w} = 0.0007$--0.006, and six others the upper edge, 0.87--0.999; only HolmII (0.36) and NGC6946 (0.44) lie in between.
The value also flips between runs: for HolmIX it is 0.002 with the transfer correction and 0.68 without it.
% numbers: best-fit eps_w (sample of max logP) from results/mcmc_<src>.BH3a.mc_0p3-10keV/best_params.txt (ULXspectra-mc
%   mc-transfer-corrections, 117-run table; summaries e597ba3), checked 2026-11-23: HolmIX 0.0017, M51ULS 0.0060, NGC1313B 0.0061,
%   NGC1313H 0.0007, NGC300 0.0011, NGC7793 0.0021; M101ULS 0.9990, M81ULS 0.9946, NGC247S 0.8945, NGC247SS 0.9820,
%   NGC5408 0.8688, NGC55 0.8688; HolmII 0.3614, NGC6946 0.4432; HolmIX nomc_0p3-10keV 0.6750.
The fits thus use $\epsilon_{\rm w}$ to adjust the brightness and do not measure it, and free in the NS fits it would most likely behave in the same way.
For a NS, however, $\epsilon_{\rm w}$ also shifts the balance between the soft emission from inside $\Rsph$ and the hard emission of the central emitter (Eq.~\ref{eq:Lcentral}).
$f_{\rm in}$ and, in NS6r and NS7r, $\eta_{\rm magn}$ control most of this balance, but the NS results hold for $\epsilon_{\rm w} = 0.5$.
% source: calculation session 2026-11-23 (the author's request: discussion of eps_w in Sect. 2.6)

{\footnotesize{The presets with the suffix ``a'' differ from their parents only in the $\Rsph$ rule, which is Ledd instead of mdot0 or P07fit.
The NS fits use NS1a, NS2, NS3a, NS4ar, NS5r, NS5ar, NS6r and NS7r.
% source: PLAN C23 (NS refits, run tag mc_0p3-10keV, start_refits_ns.sh; after the BH refits, from about 2026-11-15)
Earlier fits used the presets NS4, NS4a, NS5, NS5a, NS6 and NS7, which leave both \code{r\_in\_factor} and \code{wind\_inner\_launch\_x} free.
Only their product $\rmag/\rg$ enters the model, so one direction of the parameter space is flat, and the implied prior on $\log(\rmag/\rg)$ rises over 0--1.3 (cut at $\RNS$, 0.68), is flat over 1.3--4.0 and falls over 4.0--5.3.
It biases $\rmag$ only where the posterior reaches $\rmag \lesssim 20\,\rg$ or $\gtrsim 10^4\,\rg$.
The presets with the suffix ``r'' fix \code{r\_in\_factor} = 4.5, as NS1--NS3 do: the model is the same, and the prior on $\log(\rmag/\rg)$ is flat.}}
